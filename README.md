My structured run through core DSA patterns, solving problems in Java. Built around consistency over cramming — a fixed number of problems a day, six days a week, with a review day built in.

## 🎯 Goals

- Solve 150 pattern-representative problems across all major topics
- Recognize the ~15 patterns that repeat across most problems, instead of memorizing individual solutions
- Get comfortable reasoning about time & space complexity on sight
- Keep every solution documented with the pattern it uses, not just the code
- Push consistently — visible progress over 8 weeks, tracked here

## 📌 Approach

For each problem I document:

- Problem understanding, in my own words
- Brute-force approach first, even if I don't code it
- Optimal approach + why it's better
- Java implementation
- Time & space complexity
- Key pattern / takeaway — the thing I want to remember weeks from now
